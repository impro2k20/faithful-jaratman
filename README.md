# Faithful · Жаратман

Пилот сервиса для практики слушания кыргызской речи на материале Jaratman Podcast.

- Полный выпуск с синхронными кыргызскими и русскими субтитрами.
- Предложения исправлений, контекст соседних фраз и экспорт отдельной очереди.
- Сворачиваемый список 25 частых слов с переводами и частотами.

## Запуск

Нужен Python 3. Из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сборка и API-ключи для просмотра не нужны. Для видео нужен интернет. Для размещения используйте файлы репозитория на статическом хостинге.

## Данные и ограничения

Выпуск: «Мубарак кантип башталган? / Азамат Аматов / Жаратман подкаст».
Источник: https://www.youtube.com/watch?v=0QSvacqxnN0

Тайминги и распознавание автоматические. Полная ручная сверка с аудио не выполнена. Подсказки отмечают возможные проблемы, а не доказанные ошибки. Частоты рассчитаны по словоформам, без объединения окончаний.

Правки и черновики хранятся в localStorage браузера. Общая серверная база и независимая модерация не подключены. При смене адреса сайта очередь не переносится: заранее выгрузите предложения. Исходное аудио и ключи не включены.

## Файлы

- `index.html`, `viewer.css`, `sync.js` — текущий интерфейс.
- `sync-data.json` — синхронные двуязычные субтитры.
- `vocabulary.json` — частоты и метод подсчёта.
- `full.html` и связанные файлы — предыдущий интерфейс, сохранённый для доступа к прежним правкам.
